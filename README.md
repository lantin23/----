# 枪头整齐度自动检测系统

一个面向实验室自动化的移液枪头（pipette tip）整齐度视觉检测系统：通过摄像头实时检测枪头是否排列整齐，并通过串口控制下位机完成「震荡 → 检测 → 决策 → 进行下一步」的闭环动作。

## 功能特性

- **视觉检测**：识别枪头尾部圆形截面与散落枪头，判定「整齐 / 不整齐」。
- **串口硬件控制**：通过 ASCII 指令控制下位机震荡、LED 照明、进行下一步。
- **ACK 回传抗干扰**：每条指令发送后等待下位机 `OK` 确认，超时自动重发。
- **自动闭环控制**：震荡 → 静止 → 检测 → 整齐则 NEXT；不整齐则再次震荡，连续 3 轮不整齐提示手动整理。
- **配置驱动**：串口、指令协议、ACK、控制时序、检测阈值全部由 `config.json` 配置。
- **日志记录**：控制台 + `logs/app.log` 双路日志。

> 注：程序**不包含模拟（虚拟）模式**，必须连接真实串口硬件才能运行自动控制流程。

## 硬件要求

| 硬件 | 用途 | 说明 |
|------|------|------|
| 下位机（Arduino / STM32 等） | 执行震荡、LED、下一步动作 | 通过 USB 转串口与电脑连接 |
| 摄像头（USB / 工业相机） | 实时采集枪头画面 | 默认设备号 `0`，多相机时在配置里调整 |
| LED 照明 | 检测时补光 | 由下位机按 `LED_ON` / `LED_OFF` 控制 |

下位机固件需实现本文档的「串口通信协议」，并在执行完每条指令后回传 `OK`。

## 安装

需要 Python 3.8+，在 Windows 上运行（相机使用 DirectShow 后端）。

```bash
pip install -r requirements.txt
```

依赖：

- `opencv-python >= 4.5.0`
- `numpy >= 1.20.0`
- `pyserial >= 3.5`

## 快速开始

1. 连接下位机（串口）与摄像头。
2. 按需修改 `config.json`（如串口名、震荡时长、相机设备号）。
3. 运行：

```bash
python main.py
```

4. 主菜单：

```
1. 参数配置
2. 自动震荡控制 (串口+硬件)
3. 相机预览 / 切换
4. 退出程序
```

选 `2` 进入自动控制流程。启动时会先询问是否调整检测参数（回车跳过）。

## 串口通信协议

指令采用 **ASCII 文本 + 换行符（`\n`）**，默认协议如下（可在 `config.json` 的 `commands` 段自定义）：

| 指令 | 动作 |
|------|------|
| `SHAKE_ON`  | 开始震荡 |
| `SHAKE_OFF` | 停止震荡 |
| `NEXT`      | 进行下一步动作 |
| `LED_ON`    | 打开 LED 照明 |
| `LED_OFF`   | 关闭 LED 照明 |

### ACK 回传（抗干扰）

下位机收到并**执行完**指令后，应回传一行 `OK\n` 表示确认。

- 软件发送后等待 ACK（`ack.timeout` 秒，默认 1.5s）。
- 未收到则自动重发，最多额外重发 `ack.retries` 次（默认 2 次，总尝试 3 次）。
- 全部失败则返回 `False`，程序终止当前控制流程并报「硬件通信异常」。
- ACK 匹配忽略大小写；`ack.enabled = false` 可关闭等待（不推荐）。

## 自动控制流程

```
打开 LED
  └─ 第 1 轮：开始震荡(SHAKE_ON) → 震荡 60s → 停止(SHAKE_OFF)
       → 静止等待 → 抓帧检测
       ├─ 整齐   → 发送 NEXT，结束
       └─ 不整齐 → 进入下一轮震荡（最多 3 轮）
  └─ 连续 3 轮不整齐 → 提示用户手动整理 → 确认后发送 NEXT
关闭 LED
```

关键时序参数（`config.json` 的 `auto_control` 段）：

| 参数 | 默认 | 说明 |
|------|------|------|
| `camera_index` | 0 | 摄像头设备号（多相机时调整） |
| `shake_seconds` | 60.0 | 单轮震荡时长（秒） |
| `settle_seconds` | 5.0 | 停止后等待枪头静止的时长（秒） |
| `max_rounds` | 3 | 最大震荡轮数 |
| `capture_frames` | 3 | 每次抓帧数（取最后一帧） |
| `frame_width` / `frame_height` | 1280 / 720 | 采集分辨率 |
| `show_preview` | true | 是否显示检测预览窗口 |
| `led_enabled` | false | 是否启用 LED 照明控制（无 LED 硬件时设为 false） |

## 配置文件说明（config.json）

配置在启动时读取，缺失项自动使用默认值（深合并）。

| 段 | 说明 |
|----|------|
| `serial` | 串口名（`null` = 自动检测，检测不到则报错）、波特率、超时 |
| `commands` | 指令协议文本 |
| `ack` | ACK 回传参数（开关 / 期望内容 / 超时 / 重试次数） |
| `auto_control` | 自动控制时序参数 |
| `detector` | 视觉检测阈值 |
| `logging` | 日志级别、目录、文件名 |

## 检测原理与关键阈值

默认使用 `circle` 模式：检测枪头尾部圆形截面（霍夫圆），并结合散落枪头检测。

### 整齐度判定相关

| 参数 | 默认 | 含义 |
|------|------|------|
| `min_tips` | 4 | 最少枪头数，低于则判不整齐 |
| `slot_alignment_tolerance` | 12.0 | 同一槽内枪头共线的像素容差 |
| `outlier_ratio_threshold` | 0.15 | 槽内异常点比例阈值 |
| `min_tips_per_slot` | 2 | 每个槽最少枪头数 |
| `check_uniform_spacing` | false | 是否启用严格相邻间距均匀性检查 |

### 圆形检测（霍夫）

| 参数 | 默认 | 含义 |
|------|------|------|
| `hough_min_dist` | 25.0 | 圆心最小距离 |
| `hough_param1` | 80.0 | Canny 高阈值 |
| `hough_param2` | 20.0 | 累加器阈值（越小检测越多） |
| `hough_min_radius` / `hough_max_radius` | 10 / 40 | 半径范围 |
| `circle_merge_ratio` | 0.5 | 重叠圆合并比例 |
| `intensity_diff_threshold` | 15.0 | 圆心强度差验证阈值（0 关闭） |

### 散落枪头检测

| 参数 | 默认 | 含义 |
|------|------|------|
| `fallen_tip_min_aspect` / `fallen_tip_max_aspect` | 1.6 / 4.5 | 细长形散落枪头长宽比范围 |
| `fallen_tip_min_area` / `fallen_tip_max_area` | 300 / 20000 | 面积范围 |
| `fallen_tip_max_count` | 0 | 容忍的散落枪头数（0 = 不容忍） |
| `full_tip_min_area` 等 | — | 完整散落枪头（可见长锥形）判别 |
| `diag_tip_min_angle` / `diag_tip_max_angle` | 25 / 75 | 斜跨枪头角度范围 |

> 完整参数与含义见 `config.json` 及 `config.py` 中的中文注释。

## 常见问题

**1. 程序启动后不启动相机？**
相机只在「自动震荡控制」里、且**串口成功连接后**才会打开。若串口未接，流程会在串口检查处退出，不会碰相机。

**2. 提示「打开失败：未检测到可用相机」？**
按提示依次检查：USB 相机是否连接、是否被其他程序占用、Windows「设置 → 隐私 → 相机」是否允许桌面应用访问。

**3. 有多个相机（内置 + USB），想切换到外置摄像头？**
在主菜单选 `3. 相机预览 / 切换`，列出所有可用相机并逐台预览确认，选定后自动保存为默认；也可直接在 `config.json` 里把 `auto_control.camera_index` 改成对应设备号（0 / 1 / 2 …）。

**4. 提示「硬件通信异常（ACK 超时）」？**
检查串口名 / 波特率是否正确，下位机是否实现了 `OK` 回传协议。

**5. 没有窗口 / 窗口一闪而过？**
预览窗口只在检测阶段短暂显示（震荡 + 静止结束后）。可先把 `shake_seconds` 调小进行联调。

## 开发 / 测试

`verify_all.py` 是对 13 张样例图（6 张整齐 + 7 张不整齐）的批量回归脚本，用于验证检测器改动不破坏分类正确性：

```bash
python verify_all.py
```

（脚本内图片目录路径为开发环境硬编码，使用前需按需修改。）
